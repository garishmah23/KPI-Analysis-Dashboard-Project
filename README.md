# KPI Analysis Dashboard 📊

## Project Overview

This project analyzes e-commerce sales data using Python, Pandas, and Matplotlib. The objective is to calculate key business metrics (KPIs), visualize performance, and generate actionable insights from sales data.

## Features

* Calculate Total Sales
* Calculate Total Profit
* Calculate Total Orders
* Calculate Average Order Value (AOV)
* Analyze Sales by Region
* Analyze Sales by Category
* Generate Business Insights
* Create Data Visualizations
* Export Analysis Report to Text File

## Technologies Used

* Python
* Pandas
* Matplotlib
* VS Code

## Dataset

The dataset contains the following columns:

| Column   | Description       |
| -------- | ----------------- |
| OrderID  | Unique Order ID   |
| Date     | Order Date        |
| Region   | Sales Region      |
| Category | Product Category  |
| Sales    | Revenue Generated |
| Profit   | Profit Earned     |

## KPIs Calculated

### 1. Total Sales

Measures total revenue generated.

### 2. Total Profit

Measures total profit earned.

### 3. Total Orders

Counts total orders processed.

### 4. Average Order Value

Average revenue generated per order.
